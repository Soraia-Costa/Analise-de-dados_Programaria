# Análise Exploratória e Tratamento de Dados

## Sobre o projeto

Projeto desenvolvido durante a formação em Análise de Dados da Programaria, utilizando Python para explorar, analisar e tratar uma base de dados.

O trabalho aborda técnicas de análise exploratória, estatística descritiva e preparação dos dados para análises posteriores.

## Fonte dos Dados
Os dados utilizados neste projeto provêm do **Instituto Brasileiro de Geografia e Estatística (IBGE)**, referentes ao período de **2015 a 2021** , disponibilizados como material didático no curso de Análise de Dados da **PrograMaria**.

## Objetivos

- Explorar e compreender a estrutura de uma base de dados.
- Realizar filtros, agrupamentos e tabelas dinâmicas.
- Calcular medidas estatísticas, como média, mediana e desvio padrão.
- Identificar e tratar valores ausentes.
- Analisar valores discrepantes (outliers).
- Calcular intervalo de confiança.

## Ferramentas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Google Colab

## Etapas desenvolvidas

1. **Exploração dos dados:** visualização de registros, identificação de colunas, dimensões e filtros.
2. **Análise estatística:** cálculo de média, mediana, moda, mínimo, máximo e desvio padrão.
3. **Tratamento de valores ausentes:** preenchimento de informações faltantes nas colunas de gênero, idade e salário.
4. **Análise de valores discrepantes:** utilização de boxplots, desvio padrão e intervalo interquartil (IQR).
5. **Distribuição amostral:** cálculo da média amostral, erro padrão e intervalo de confiança de 95%.

O projeto permitiu praticar técnicas de exploração, limpeza e análise estatística de dados, desenvolvendo conhecimentos em Python e suas principais bibliotecas para análise de dados.
